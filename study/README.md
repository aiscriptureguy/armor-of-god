# Study Workspace

This directory contains all Phase 1 research output. Do not begin architecture or code before Gate 1 is approved.

| File | Purpose |
|------|---------|
| project-brief.md | Scope, audience, goals, acceptance criteria |
| questions.md | Study questions ranked by priority |
| sources.md | Source ledger — one SRC-XXXX entry per source |
| research-log.md | Session-by-session log of progress and decisions |
| open-questions.md | Questions not yet addressed or resolved |
| content-audit.md | Pre-publication content quality audit |
| passages/ | One file per passage record (PASS-XXXX.md) |
| themes/ | Theme notes |
| patterns/ | Pattern records |
| context/ | Historical, cultural, or literary context notes |
| decisions/ | Architecture and design decisions log |
